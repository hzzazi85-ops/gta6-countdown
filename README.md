# GTA VI — صفحة العد التنازلي (نسخة جاهزة للنشر)

## محتويات الحزمة
| الملف | الوصف |
|---|---|
| `index.html` | الصفحة كاملة (كل شي مضمن: CSS + JS + SVG بملف واحد) |
| `manifest.json` | يسمح بإضافة الصفحة لشاشة الجوال الرئيسية (Add to Home Screen) |
| `sw.js` | Service Worker بسيط — يفعّل ميزة "تثبيت التطبيق" على أندرويد/كروم ويسمح بفتح الصفحة أوفلاين بعد أول زيارة |
| `robots.txt` | يسمح لمحركات البحث بفهرسة الصفحة |
| `sitemap.xml` | خريطة الموقع لمحركات البحث |
| `README.md` | هذا الملف |

## ميزة "تثبيت التطبيق" (زر جديد بأعلى الصفحة)
يظهر تلقائياً **على الجوال فقط** (يختفي على الكمبيوتر لأنه غير مخصص له):
- **أندرويد/كروم**: لو المتصفح يدعم التثبيت المباشر، يطلع زر "ثبّت التطبيق الآن" يشغّل نافذة التثبيت الأصلية للمتصفح
- **آيفون/سفاري**: سفاري ما يدعم التثبيت المباشر من الكود، فتطلع تعليمات توضح للزائر يضغط زر المشاركة ثم "إضافة إلى الشاشة الرئيسية"
- يختفي الزر تلقائياً لو الصفحة مفتوحة أصلاً كتطبيق مثبّت

**ملاحظة**: التثبيت المباشر بأندرويد يحتاج الصفحة تكون مستضافة فعلياً عبر HTTPS (مو ملف مفتوح مباشرة) — لازم ترفعها لأحد خيارات النشر بالأسفل عشان الميزة تشتغل بكامل قوتها.

## خطوات النشر (اختر وحدة)

### الأسهل: Netlify (سحب وإفلات)
1. روح [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد الملفات كامل (الأربعة ملفات) وأفلته
3. خلاص — بتاخذ رابط جاهز فوراً، وتقدر تربط دومين خاص بك من الإعدادات

### Vercel
1. أنشئ مستودع GitHub وارفع الملفات فيه
2. سجل دخول [vercel.com](https://vercel.com) واربط المستودع → Deploy تلقائي

### GitHub Pages (مجاني بالكامل)
1. أنشئ مستودع جديد وارفع الملفات
2. من إعدادات المستودع → Pages → فعّل من فرع `main`
3. رابطك بيكون `username.github.io/repo-name`

## ✅ لازم تسويها قبل النشر الفعلي

1. **بدّل روابط `https://example.com/`** الموجودة بـ:
   - `index.html` (وسوم `og:url` و`canonical`)
   - `robots.txt` (سطر Sitemap)
   - `sitemap.xml` (كل الروابط)

   بحث سريع عن `example.com` بأي محرر نصوص وتبديله برابطك الفعلي.

2. **صورة المعاينة (OG Image)**: الوسوم `og:image` و`twitter:image` معلّقة (commented) بالكود لأنه ما قدرت أولّد صورة PNG فعلية من بيئتي الحالية (بدون اتصال إنترنت لتوليد/تحويل صور). الحل:
   - افتح الصفحة بالمتصفح، خذ لقطة شاشة بمقاس 1200×630
   - ارفعها لاستضافتك، وفعّل السطرين المعلقين بـ `index.html` وحط رابط الصورة

3. **ربط نموذج الإيميل بخدمة فعلية**: حالياً النموذج يتحقق من صحة الإيميل ويعرض رسالة نجاح، لكن **ما يخزن الإيميل فعلياً بأي مكان**. أسرع حل بدون خادم خاص:
   - سجل بـ [Formspree.io](https://formspree.io) (مجاني لحد معين)
   - بيعطونك endpoint مثل `https://formspree.io/f/xxxxxxx`
   - عدّل بـ `index.html`: أضف `action="https://formspree.io/f/xxxxxxx" method="POST"` على وسم `<form id="subForm">`، واحذف `e.preventDefault()` بجزء الجافاسكربت الخاص بالفورم (أو خليه إذا تبي تتحكم بتجربة الإرسال عبر JS)

4. **راجع تاريخ الإصدار**: حالياً مضبوط على **19 نوفمبر 2026** — عدّله بسطر `RELEASE_DATE` بالجافاسكربت لو تغيّر.

## القيود المعروفة (بدون خادم خاص)
- **تحديد الموقع تقريبي أحياناً**: لو خدمات IP محظورة بمتصفح الزائر (إضافات خصوصية، جدار حماية)، الصفحة ترجع لتقدير مبني على لغة المتصفح (تظهر عليه علامة `*`) بدل ما تفشل بالكامل.
- **النموذج لا يخزن بيانات فعلياً** إلا لو ربطته بخدمة خارجية (خطوة 3 فوق).
- **لا يوجد تتبع تحليلات (Analytics)** — لو تبيه، أضف سكربت Google Analytics أو Plausible بأول `<head>`.

## المتصفحات المدعومة
تعمل على كل المتصفحات الحديثة (Chrome، Safari، Firefox، Edge — آخر إصدارين). تعتمد على:
- CSS Grid/Flexbox/Custom Properties
- `Intl.DisplayNames` (لتقدير الموقع الاحتياطي — مدعوم بكل المتصفحات الحديثة من 2021+)
- `fetch` + `AbortController`

## فحص الجودة اللي تم عمله
- ✅ لا يوجد IDs مكررة، لا صور بدون alt، لا أكواد CSS/JS ميتة
- ✅ تطابق كامل بمفاتيح الترجمة بين اللغات الأربع (عربي/إنجليزي/إسباني/فرنسي)
- ✅ تحقق من صحة بنية HTML وتوازن الوسوم
- ✅ فحص صحة الجافاسكربت (syntax check)
- ✅ حماية من bot spam بحقل مخفي (honeypot)
- ✅ دعم قارئ الشاشة (aria labels، `.visually-hidden` للليبل)
